# What is this
This is a system allows players to move virtual table top (VTT) characters by moving QR codes on the table.

# How does this work
A phone is mounted to the ceiling beside a projector. The projector projects the game board and the phone records.

We then have the phones recording streamed to this tool where QR codes of a given actor_id within VTT are mapped to the relative position on the table.
